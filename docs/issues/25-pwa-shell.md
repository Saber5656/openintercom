# 25: PWA shell: manifest, service worker, keep-awake

## Summary

Installability and appliance polish: web manifest + icons, a conservative
service worker (app-shell caching, never APIs), the update toast, and
wake-lock lifecycle with visible status.

## Context

DESIGN §7.6/§7.7. The SW exists for fast reload and home-screen install on
Android; on iOS the supported mode is a Safari tab (ADR-006) with
add-to-home-screen as optional polish. Nothing here may ever make a station
*silently* stale or offline-broken.

## Scope

- `web/public/manifest.webmanifest`, icon generation script, SW +
  registration, update toast
- Wake-lock lifecycle integration + settings status (with 22's settings
  screen)
- In-app "install & keep-awake" guidance view (linked from onboarding ⑥ and
  settings)

## Detailed Requirements

1. Manifest: `name: "OpenIntercom"`, `short_name: "Intercom"`,
   `display: "standalone"`, `orientation: "portrait"`, theme/background from
   design tokens; icons 192/512 PNG + maskable variant, generated by
   `web/scripts/gen-icons.mjs` from a single source SVG (simple intercom
   glyph, original artwork, committed) — script runs in `build-web`.
2. Service worker (hand-rolled `web/src/sw.ts`, compiled by Vite; **no new
   runtime deps**):
   - Precache: build script `web/scripts/gen-sw-manifest.mjs` embeds the
     hashed asset list from Vite's build manifest into the SW
     (`self.__OI_ASSETS__`).
   - Fetch strategy: hashed assets cache-first; navigations (`index.html` /
     `admin/index.html`) network-first with 3 s timeout falling back to
     cache; any `/api/` or `/healthz` request **bypasses** the SW entirely
     (`fetch` passthrough, no caching — asserted by test).
   - Versioned cache names (`oi-v<build-hash>`); `activate` deletes old
     caches.
   - `skipWaiting` only on user consent: SW posts "waiting" → app shows
     toast "Update ready — reload" → user tap → `SKIP_WAITING` message +
     `location.reload()` on `controllerchange`.
3. Registration: station entry only after successful auth'd boot or
   onboarding completion (never interfere with first pairing); admin entry:
   no SW (always fresh).
4. Wake lock lifecycle (lib/wake from 19): acquire when `online` +
   `visible`; re-acquire on `visibilitychange`; release on hide? No —
   request whenever visible regardless of call state (station is an
   appliance; §7.6), and 24 additionally holds during calls. Settings line
   shows `active | unsupported | denied` live.
5. Guidance view (static, i18n): per-OS add-to-home-screen steps, keep-awake
   settings (§7.6 exact instructions), dock/power framing, iOS
   "Safari tab is fine" note, storage-eviction note for iOS (U4) with
   "use it daily / re-pair is 2 minutes" framing.
6. iOS standalone caveat: if `navigator.standalone === true` and gUM fails
   at mic priming (U4), guidance view explains falling back to the Safari
   tab — condition detected and surfaced, not silently broken.

## Acceptance Criteria

- [ ] Lighthouse PWA installability passes on Android Chrome against the
      dev hub (manual, screenshot).
- [ ] SW: `/api/*` requests reach the network with SW active (devtools +
      vitest fetch-handler unit tests with mocked caches); hashed assets
      served from cache offline; navigation offline → cached shell +
      offline banner (reconnecting state from 20 takes over).
- [ ] Update flow: deploy a changed build → toast appears ≤30 s on an open
      station (SW update check on load + every 6 h timer), tap reloads to
      new version, old caches purged.
- [ ] Icons render correctly installed (maskable check via Chrome
      devtools).
- [ ] Wake-lock status truthful on: Android Chrome (active), iOS 15 Safari
      (unsupported) — manual matrix items.
- [ ] No SW on `/admin/` (assert registration scope).

## Validation

vitest for SW fetch-routing logic (mock `caches`/`fetch`); manual install +
update-toast run on Android; device-matrix items recorded (§12.4).

## Dependencies

19, 21.

## Non-goals

Offline calling (impossible), push (ADR-006), precaching API data,
workbox adoption.
